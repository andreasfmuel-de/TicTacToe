**Direkte Git-Aktionen auf Seite 1**

- Änderungen: VS-Code-Quellcodeverwaltung öffnen.
- Stage / Add: `git.stageAll` – ALLE Änderungen im gewählten Repository stagen.
- Commit: `git.commitStaged` – nur bereits gestagte Änderungen; Nachricht in VS Code eingeben.
- Fetch: `git.fetch`.
- Pull: `git.pull`, vorhandene Einstellungen respektieren.
- Push: `git.push`.
- Branch: `git.checkout`.
- Historie: `workbench.scm.history.focus`.

Die Vorlage verwendet für Stage / Add bis Historie der Reihe nach Strg+Alt+F1 bis F7. Prüfe die Verfügbarkeit der Befehle in meiner VS-Code-Version.

**Terminal-Tasten auf Seite 2**

Die folgenden Texte ausschließlich ins VS-Code-Terminal einfügen, OHNE Enter oder automatische Ausführung:

- Status: `git status`
- Pull: `git pull --ff-only`
- Add: `git add .`
- Commit: `git commit -m "`
- Push: `git push`
- Branch: `git branch --show-current`
- Log: `git log --oneline --graph --decorate -15`

Hierfür verwendet die Vorlage Strg+Alt+F13 bis F19. „Repo“ öffnet die Quellcodeverwaltung.
